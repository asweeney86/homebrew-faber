# Homebrew tap for Faber

[Faber](https://github.com/asweeney86/faber) is a local-first, AI-enriched memory for the documents you open at work.

```bash
brew install asweeney86/faber/faber
faber setup
```

Upgrade with `brew upgrade faber`. The background service restarts into the new version by itself. Your data is backed up before any schema change.

`Formula/faber.rb` is generated by the Faber release workflow. Don't edit it here: change `scripts/release-lib.ts` in the main repository instead. This tap's own workflow fetches the formula from every new release, and then installs it on a clean macOS runner to make sure it works.
